# Footprints

一个属于 vi 的中文个人博客，聚焦生活与技术。所有初始文章都明确标注为示例。

写作工作台延续纸白与松绿配色：桌面左侧是草稿／已发布列表，右侧是文章编辑纸面；手机按文章列表、编辑器自然排列。正文编辑使用清楚的标签与 Markdown 工具栏，阅读预览保持原文章样式。草稿保存和公开发布是两个独立动作；发布后的私密修改也需要明确更新发布。

色彩：雾白 #f7f9f6、纸白 #ffffff、松绿 #315a46、墨绿 #233a30、淡叶绿 #e9f0e8、蜂蜜黄 #dbc484。

字体：英文品牌用 Georgia，中文标题用 Noto Serif SC / 宋体，正文用系统无衬线。标题靠字号和间距建立层次，不用杂乱装饰。

布局：居中的宽阅读区域。左侧主标题、右侧山湖明信片；下方双列文章与窄个人侧栏。手机按自然顺序流式排列。

```text

```

审阅：主视觉的明信片来自“足迹”的记录语义。为避免通用产品展示页，删除无意义统计、订阅表单和功能卖点；使用真正的文章、独立阅读页和归档。只给摄影框轻阴影，内容卡片用边框。动画仅用于响应操作。尊重 reduced-motion；移动端菜单、焦点和暗色模式完整。
